Overview of consultant and finance features

💼 Consultant Features

Submit and manage your expenses

Dashboard

Overview of your monthly expenses, approved total, flagged receipts, and recent activity at a glance.

My Expenses

View all submitted expenses with filters by status (submitted, approved, flagged), type, and date range. Click any expense to see details.

Expense Detail

View receipt details, daily food cap summary for that day, flag reason (if flagged), and communicate with finance about issues.

Create New Expense

Submit a single receipt with description, type, amount, currency, region, project, and image. See live warnings if you exceed daily food caps (£40/day, £25 dinner, £15 lunch, £10 breakfast).

Multi-Receipt Batch Upload

Fast-track multiple expenses at once. Set project, region, and currency at the top — then edit description, type, amount, and date for each expense. Total updates in real-time.

Expense Types

Save templates for your most common expense settings (currency, region, project). When creating an expense, select a type to auto-fill these fields — saves time on repetitive data entry.

📊 Finance Features

Review, approve, and flag submitted expenses

Flagged Queue

See all receipts flagged for review (over daily cap, missing info, duplicates, etc.). Filter by flag reason, submitter, or region. Quick stats show pending items and total at risk.

Review Expense

Review a flagged receipt with full details, receipt image, daily food cap breakdown for that date, and why it was flagged. Choose to approve, reject, or partially approve (e.g., approve £25 of a £62 dinner). Communicate directly with the submitter.

All Expenses

Full view of all submitted expenses (247+ at a time) across all consultants. Filter by status, submitter, type, or date range. Export for reporting.

Statistics Dashboard

Monitor key metrics: total expenses, total amount, flagged count, approved count. See breakdown by expense type, top submitters, common flag reasons, and queue health (pending, aging, overdue).

Communication Thread

Built-in messaging between finance and submitter on each flagged receipt. Discuss issues, request additional info, or explain decisions without leaving the app.

✨ Key Features (Both Roles)

Daily Food Cap Tracking

Real-time display of daily food allowance (£40/day total, with sub-caps for breakfast, lunch, dinner). Warns consultants before they exceed limits; helps finance identify violations.

Flexible Filtering

Filter expenses by status, type, date range, amount, submitter, region, and more. Export data for reconciliation and reporting.

Receipt Images

Drag-and-drop or click-to-upload receipt images. Finance can view receipts inline when reviewing flagged expenses.

Two-Way Communication

Message thread on each flagged expense. Consultants can explain, finance can ask questions — all in one place.

Batch Operations

Submit multiple receipts at once with shared settings (project, currency, region), then customize each item. Saves time on repetitive submissions.

Saved Templates

Create expense types to auto-fill common settings. No need to re-enter project/currency/region every time.
