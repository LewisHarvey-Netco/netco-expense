# Netcompany App Design Guidelines

## Visual Style
- Clean, precise, technical, modern, editorial.
- Structured layouts with strong alignment and whitespace.
- Prioritise usability and clarity over decoration.
- Avoid generic SaaS styling, excessive rounded corners, gradients, heavy shadows, and unnecessary visual effects.

### Colour Rules
- Never use pure black for normal text; use `#141E1E`.
- Green, Green 10%, and White should be the dominant colours.
- Use Coral sparingly for attention, emphasis, or important highlights.
- Do not introduce arbitrary colours.
- Maintain accessible colour contrast.

## Typography
- Primary font: **Studio 6**.
- Use **Regular** by default.
- Use **Demibold/Bold** only for hierarchy and emphasis.
- Fallback font: **Arial**.
- Keep typography simple with a small, consistent type scale.
- Typography should feel tight, precise, and technical.

## Layout
- Use a flexible **4×4 grid** as the underlying layout principle.
- Maintain strong horizontal and vertical alignment.
- Use consistent spacing and margins.
- Prioritise clear hierarchy and whitespace.
- Adapt the grid responsively rather than abandoning it on smaller screens.

## 5th Element
- Use the Coral `#FF6359` 5th Element sparingly.
- Maximum **one prominent occurrence per page/view**.
- Suitable for page headers, major titles, section breakers, underlines, bullets, or focus points.
- It is a brand accent, not general decoration.

## UI Principles
- Functional components should remain conventional and intuitive.
- Prefer clear hierarchy over visual complexity.
- Use subtle Green tints for surfaces, borders, and secondary states.
- Keep interactions and states visually consistent.
- Accessibility takes priority over strict brand styling.

## AI Implementation Rule

When designing UI, use Netcompany's visual language rather than generic SaaS styling. Prioritise precision, structure, restraint, accessibility, strong alignment, and clear information hierarchy. Use the defined Netcompany colour palette and Studio 6 typography. Coral is an accent only. Do not invent colours or unnecessary decorative elements.
